VF-54 · architecture decision

FLORA chooses continuity, then behaves like a session.

Only wake-word dictations are classified. The choice is binary: reuse the current FLORA conversation or create a fresh one. Older conversations are never searched or selected.

SurvivorEphemeral Luna classification + one stable assistant:flora adapter over the native Assistant history and existing 1–9 slot system.

The decision in three cuts

CONTINUITY

Luna, low reasoning

Schema-constrained current-vs-new preflight. Empty drafts skip the model. Any timeout, invalid response, or low confidence safely reuses today's thread.

IDENTITY

One stable FLORA endpoint

The picker targets FLORA's current conversation through assistant:flora. A conversation rollover does not change her hotkey slot.

ARRIVAL

Receipt, never takeover

Closed-panel work produces one-line working/new-message receipts and unread state. The full reply appears only after explicit hotkey, pill, or panel selection.

Elimination trail

Fixed reuse / fixed new

Each fails half the goal: unrelated topics leak context, or follow-ups lose it.

Heuristics / embeddings

Semantic continuity is the hard part; these add silent errors or extra infrastructure without stronger judgment.

Choose among all histories

Eliminated by the explicit current-or-new constraint. The system never guesses which old thread the user meant.

Fake MCP / duplicate SessionPush store

Breaks lifecycle invariants or creates two durable owners for FLORA's text and consumption state.

Universal session refactor

Rewrites stable MCP behavior for a single local endpoint and has a much larger failure surface.

Ephemeral classifier + local adapter

Uses existing auth, source-of-truth history, slots, hotkeys, speech, and grown routing with explicit MCP guards.

Build contract

CLASSIFY
Only matched FLORA dictations. Current title + six recent non-note messages, capped at 6k characters. Luna low, schema output, 15-second timeout.
FAIL SAFE
Reuse on infrastructure failure, malformed output, or confidence below 0.65. A stale result is never applied after the active conversation changes.
ROUTE
reuse preserves the UUID/thread. new calls only createConversation. No older conversation is activated.
PRESENT
Stable assistant:flora slot. Hidden-panel replies set unread and flash receipts; explicit selection reveals and consumes them.
ISOLATE
Local IDs never enter MCP registry, inbox, push persistence, overlays, asks, or remote completion paths.
ROLL BACK
Remove the classifier/adapter and stop writing the optional seen bit. Existing Assistant and MCP data remain readable.
