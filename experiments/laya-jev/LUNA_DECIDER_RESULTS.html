Across all six longest-context requests, median latency was 0.692 s for Luna and 12.578 s for Decider. The identical states produced roughly 98K billed input tokens for Luna and 274K for Decider with two questions. Usage counts can aggregate repeated state across questions: they are billing measurements, not a direct measurement of usable context. Maximum advertised windows were not exhaustively tested.

At 128 questions, Jev cost about 11× less than Luna and 32× less than Decider in this example. All 128 answers were correct for each; Luna also passed 200/200. Each also matched the correct label in eight separate tests with 8, 32, 64 and 128 choices. One batch at each size is a capability check, not a throughput benchmark.

Practical choice

Start with Decider for a quality-focused pilot on narrow decisions, then validate against real labeled Voice Flow examples. Keep Jev as a useful baseline, especially when many questions share the same state. Luna is worth considering for long-input or image-heavy paths, but its short arithmetic and logic errors here argue against a blanket replacement.

Decider publishes Apache-2.0 weights and an inference example; its model card identifies a Qwen3.8-27B fine-tune. The vendor example calls for Python 3.12+ and CUDA, with roughly 49 GiB of weights plus working memory. That gives you a downloadable starting checkpoint for adaptation; this experiment neither downloads those weights nor verifies a full training recipe or scaling procedure. Jev and Luna were tested as hosted models.

Use the same output folder to resume only if code and inputs are unchanged. The $0.50 reported-cost stop acts between requests; it is not a provider-enforced hard cap.

Evidence and limitations

This is a synthetic, authored diagnostic suite, not a representative benchmark. Translations, paired states and multi-question cases are correlated. No thresholds were tuned against these results; high-probability error counts do not establish production calibration. Core network timing came from one pass on this Mac; some image-format exploration overlapped a portion of it. Small latency differences should not be treated as a stable ranking. The full vision run followed the main run.
